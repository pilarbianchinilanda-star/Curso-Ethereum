# Curso-Ethereum
KipuBank V2 es un contrato bancario descentralizado multi-token que permite depósitos y retiros tanto en Ether como en tokens ERC-20, con conversión automática a USD mediante oráculos de Chainlink.
Implementa control de acceso basado en roles, límites globales de depósito y una contabilidad interna segura y eficiente.
